# 银河奶牛 · 攒钱（MWI Savings）

一个给 [银河奶牛（Milky Way Idle CN）](https://www.milkywayidlecn.com/) 用的 Tampermonkey 用户脚本：把**心愿单、置换、市场行情和攒钱进度**放在一个面板里。

> 非官方脚本，与游戏官方无关。脚本只匹配银河奶牛国服域名，不上传账号数据。

## 功能

- **心愿**：搜索物品（中文 / 英文 / 迷宫物品），设置强化等级和数量，按优先级排序；部分拥有的物品自动从缺口扣除。
- **置换**：从库存选择要卖掉的物品，设置数量；所有置换共用一个资金池，按优先级抵扣心愿，剩余自动顺延。
- **评估**：当前金币、税后置换市值、心愿总价、还差、总进度、预计天数；逐项显示已攒比例、缺口、成本、已拥有。
- **4% 置换税**：置换物品按卖出处理，按买价或卖价估值都扣 4%；心愿是购买，不扣税。
- **刷新价格 / 刷新库存**：手动刷新行情；库存优先读取游戏实时状态，读不到时回退到最近一次同步并提示。
- **Tampermonkey 存储**：心愿、置换、行情/目录/中文名缓存优先写入 GM 存储；旧 localStorage 数据自动迁移；GM 不可用时回退 localStorage。
- **迷宫物品中文名**：内置开路者 / 探路者 / 寻路者靴、磁石、生活披风、封印、火把、斗篷、信标、补给箱、紫多拉之盒等中文名，支持中文搜索。
- **切角色自动收起**：点击切换角色或进入角色选择界面时自动关闭面板，新角色数据到达后重新挂载页签。
- **图标悬停**：物品列只显示图标，鼠标悬停查看完整名称、强化、精炼和库存。

## 安装

### 1. 安装 Tampermonkey

在浏览器扩展商店安装 Tampermonkey：

- Chrome / Edge：Chrome Web Store 搜索「Tampermonkey」
- Firefox：Firefox Add-ons 搜索「Tampermonkey」
- Safari：App Store 搜索「Tampermonkey」

官方地址：<https://www.tampermonkey.net/>

### 2. 安装脚本

- GitHub 仓库：<https://github.com/im630/mwi-savings>
- GitHub Raw：<https://raw.githubusercontent.com/im630/mwi-savings/main/mwi-savings.user.js>
- Greasy Fork：待发布（发布后补上脚本页链接）

打开链接后 Tampermonkey 会弹出安装页，点击「安装」。

如果浏览器没有弹出安装页：

1. 复制 `.user.js` 链接到地址栏打开；
2. 或在 Tampermonkey 里新建脚本，把 `mwi-savings.user.js` 的全部内容粘贴进去，保存。

### 3. 打开游戏

访问 <https://www.milkywayidlecn.com/>，页签栏「配装」右边会出现「攒钱」。

第一次安装时 Tampermonkey 可能提示新权限（`unsafeWindow`、`GM_xmlhttpRequest`、`cdn.jsdelivr.net` / `unpkg.com`），允许即可。

## 使用

### 心愿

1. 在搜索框输入中文 / 英文 / 「迷宫」等关键词，选择物品；
2. 装备类输入强化等级 0–20，材料 / 消耗品为 0；
3. 设置数量，点击「添加」；
4. 用 ↑ / ↓ 调整优先级，点「删除」移除；
5. 已拥有数量会自动从缺口扣除，并计入进度。

### 置换

1. 从库存搜索结果中选择要卖掉的物品，设置数量；
2. 置换物品按优先级共用一个资金池，先抵扣排在前面的心愿，剩余自动顺延；
3. 小计和置换市值已扣 4% 税。

### 评估

- 顶部卡片：当前金币、置换市值(税后)、心愿总价、还差、总进度、预计天数；
- 逐项：已攒比例、还差、成本、已拥有 / 总数；
- 「每日利润」填 M 为单位（例如 100 表示 100M/天），用于估算天数。

### 刷新

- **刷新价格**：重新拉取同源 `marketplace.json`；行情缓存 10 分钟；
- **刷新库存**：优先读取游戏实时状态（若安装了 mooket，会读取 `mwi.game.state`；也支持 `game.state` / `__game.state`），读不到时使用最近一次 WebSocket 同步，并在面板里提示；如果数据仍未变化，刷新页面后再试。

### 清空

右上角「清空」会清空心愿和置换列表（有二次确认），不影响行情/物品目录缓存。

## 计算规则

- **进度 = 已攒比例**：`(已拥有 + 资金已覆盖数量) / 总数量`；
- **部分拥有**：`缺口 = 数量 - 已拥有`；已拥有计入进度，不占资金；
- **置换资金池**：所有置换价值先加总，再按心愿优先级抵扣；前面的心愿用完后，剩余资金顺延到后面的心愿；
- **置换与心愿重复**：同一物品既在置换又在心愿时，置换数量会从心愿的已拥有里扣除，避免重复计算；
- **4% 税**：置换卖出按 `价格 × 数量 × 0.96`；心愿购买不扣税；
- **无报价**：某一侧没有报价时按另一侧估算；两侧都没有则标「无报价」，不计入总额并给出提示；
- **预计天数**：`ceil(还差 / 每日利润)`。

## 权限与隐私

| 权限 | 用途 |
| --- | --- |
| `GM_getValue` / `GM_setValue` | 在 Tampermonkey 本地保存心愿、置换、行情和缓存 |
| `GM_xmlhttpRequest` + `@connect cdn.jsdelivr.net` / `unpkg.com` | 拉取中文物品名映射 |
| `unsafeWindow` | 监听游戏 WebSocket 库存消息、读取页面实时状态 |

- 脚本只匹配 `https://www.milkywayidlecn.com/*` 和 `https://milkywayidlecn.com/*`；
- 行情请求是同源 `GET /game_data/marketplace.json`；
- 中文名从 jsDelivr / unpkg 获取，不包含账号数据；
- **不上传**心愿、置换、库存、金币或任何账号数据；没有后端、统计或广告。

## 数据存储

| Key | 内容 |
| --- | --- |
| `mwi.savings.v1` | 心愿、置换、设置、UI 状态 |
| `mwi.savings.market.v1` | 行情缓存 |
| `mwi.savings.catalog.v3` | 物品目录缓存 |
| `mwi.savings.names.v1` | 中文名缓存 |

- 优先使用 Tampermonkey 存储；GM 不可用时回退 localStorage；
- 首次运行会把旧的 localStorage 状态迁移到 GM；
- 清除浏览器站点数据不会删除 GM 存储；卸载脚本、更换 namespace 或重装可能导致数据不可见，操作前先备份。

## 常见问题

### 页签没有出现

- 确认 Tampermonkey 和脚本都已启用；
- 刷新游戏页面；
- 确认地址是 `www.milkywayidlecn.com` 或 `milkywayidlecn.com`；
- 打开控制台看是否有 `[攒钱]` 日志或报错；如果和其他插件冲突，逐个禁用定位。

### 刷新库存后数字没变

- 面板会提示「实时」或「最近一次同步」；
- 提示「最近一次同步」说明没读到游戏实时状态，刷新页面后再试；
- 若安装了 mooket，脚本会优先读取 `mwi.game.state`；
- 仍不更新，请把控制台 `[攒钱]` 日志和面板提示一起反馈。

### 价格显示 — 或「无报价」

- 点击「刷新价格」；
- 行情缓存 10 分钟，刚刷新过可能还是缓存；
- 物品可能没有卖单 / 买单，或本身不可交易。

### 置换税

- 置换物品都按卖出处理，按买价或卖价估值都扣 4%；
- 心愿是购买，不扣税。

### 切角色后面板

- 点击切换角色 / 进入角色选择界面时，面板会自动关闭；
- 新角色数据到达后，页签会自动重新挂载。

### 数据备份

- 数据在 Tampermonkey 存储中，更新脚本一般会保留；
- 更换 namespace、卸载重装前，建议在 Tampermonkey 的存储页面查看/备份，或手动记录心愿和置换。

## 兼容性

- 主要测试：Chrome / Edge + Tampermonkey；
- Firefox + Tampermonkey 理论可用；Violentmonkey 对 `GM_*` 兼容，但未完整测试；
- 与收益、mooket 等插件共用页面；如果页签或面板冲突，逐个禁用定位。

## 开发

- 单文件：`mwi-savings.user.js`，无构建步骤；
- 关键函数：`hookWS`（WebSocket 库存）、`buildCatalog`（物品目录）、`evaluate`（资金池 / 进度）、`refreshInventory`（库存刷新）；
- 本地测试：Tampermonkey 新建脚本粘贴，使用干净浏览器配置测试安装、权限和更新；
- 发布前：修改 `@version`、`@license`，替换 README 里的 Greasy Fork 链接；
- 税率按当前 4% 卖出税写在 `SWAP_TAX`；如游戏调整，改这个常量；
- 内嵌 LZ-String 1.4.4 的 `decompressFromUTF16` 可读实现（MIT），用于解压 `localStorage.initClientData`；不再包含压缩/混淆库。
